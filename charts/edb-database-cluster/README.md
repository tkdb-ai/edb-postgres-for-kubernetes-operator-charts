# edb-database-cluster

![Version: 0.1.0](https://img.shields.io/badge/Version-0.1.0-informational?style=flat-square) ![Type: application](https://img.shields.io/badge/Type-application-informational?style=flat-square) ![AppVersion: 18.6](https://img.shields.io/badge/AppVersion-18.6-informational?style=flat-square)

Helm chart to deploy a PostgreSQL `Cluster` custom resource managed by the
[edb-postgres-for-kubernetes](../edb-postgres-for-kubernetes) operator.

> This chart does **not** install the operator or its CRDs. Install the
> `edb-postgres-for-kubernetes` chart (or an equivalent operator deployment)
> into the cluster first.

**Homepage:** <https://www.enterprisedb.com/products/postgresql-on-kubernetes-ha-clusters-k8s-containers-scalable>

## Usage

```bash
helm install my-cluster charts/edb-database-cluster -n my-namespace
```

> **Note:** `plugins` registers the
> [cnpg-i-sidecar](https://github.com/tkdb-ai/cnpg-i-sidecar) plugin by
> default, with a placeholder `image` value (and `sidecarScripts` creates
> the ConfigMap it references, with an example crontab/script). This
> requires the plugin's own controller to already be deployed in the
> cluster (it's a separate component, not something this chart installs) -
> if it isn't, either deploy it first, or pass `--set plugins=null` /
> `--set-json 'plugins=[]'` to disable registration entirely.

To override the sidecar plugin's placeholder image and its crontab/scripts
with real ones - see
[`examples/with-sidecar-plugin-values.yaml`](examples/with-sidecar-plugin-values.yaml)
for the full values and prerequisites:

```bash
helm install my-cluster charts/edb-database-cluster -n my-namespace \
  -f charts/edb-database-cluster/examples/with-sidecar-plugin-values.yaml
```

To enable backups to an S3-compatible object store:

```bash
helm install my-cluster charts/edb-database-cluster -n my-namespace \
  --set backup.enabled=true \
  --set backup.barmanObjectStore.destinationPath=s3://my-bucket/ \
  --set backup.credentials.accessKeyId=<key-id> \
  --set backup.credentials.secretAccessKey=<secret-key>
```
